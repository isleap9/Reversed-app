<objective>
Close verification gap G-06-OPT-02 (code review CR-02). DISM exit 3010 means success, restart required, and DISM returns it because /NoRestart is passed. The app currently treats it as failure, so for WSL, Hyper-V, Windows Sandbox and .NET 3.5 the user sees "Enable failed", no restart notice and a stale list. Also fold in WR-03 (feature name as a discrete argv element), IN-02 (dism.exe from System32), the WR-08 minimum guard, WR-07, IN-04, and UI-review top fix 2 (one state-dependent button per row).

Purpose: OPT-02 "User can enable/disable an optional feature" reports the truth for every feature, including the ones that need a reboot.
Output: `FeatureChangeResult`, a hardened `OptionalFeaturesService`, a restart-aware `OptionalFeaturesViewModel`, and the single-button row layout.
</objective>
