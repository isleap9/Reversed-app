### 2. Installed Apps Page

**File:** `src/VainTools.App/Features/Apps/InstalledAppsPage.xaml`  
**Code-behind:** `src/VainTools.App/Features/Apps/InstalledAppsPage.xaml.cs`  
**ViewModel:** `src/VainTools.App/ViewModels/InstalledAppsViewModel.cs`  
**Service:** `src/VainTools.App/Services/InstalledAppsService.cs` (new, direct registry read)

#### Layout Structure

```
InstalledAppsPage (Page)
└── Grid (Padding=24)
    ├── Row 0: Header
    │   ├── StackPanel
    │   │   ├── TextBlock "Installed Apps" (TitleTextBlockStyle)
    │   │   └── TextBlock subtitle (TextFillColorSecondaryBrush)
    │   └── StackPanel (right-aligned)
    │       └── Button "Refresh"
    ├── Row 1: InfoBar (elevation warning, conditional)
    ├── Row 2: Search Box
    │   └── AutoSuggestBox / TextBox (filter)
    ├── Row 3: Program List (custom card)
    │   └── Border (card)
    │       └── StackPanel
    │           ├── TextBlock "Programs" (SubtitleTextBlockStyle)
    │           ├── TextBlock count (TertiaryBrush, 12pt)
    │           └── ItemsControl (ProgramsHost)
    │               └── DataTemplate: InstalledAppViewModel
    │                   └── Border (program card)
    │                       └── Grid
    │                           ├── Column 0: StackPanel
    │                           │   ├── TextBlock program name (SemiBold)
    │                           │   ├── TextBlock publisher (TertiaryBrush, 12pt)
    │                           │   └── TextBlock version (TertiaryBrush, 11pt)
    │                           └── Column 1: StackPanel (right-aligned, Spacing=8)
    │                               ├── Button "Uninstall" (destructive)
    │                               └── Button "Copy Command"
    └── Row 4: ProgressRing (loading, conditional)
```

#### Data Flow

1. `InstalledAppsViewModel` calls `InstalledAppsService.GetInstalledAppsAsync()` on initialization.
2. Service reads `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`, `HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall`, and `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`.
3. Program list populates the `ItemsControl`.
4. "Uninstall" button triggers confirmation dialog.
5. On confirm, calls `Process.Start(UninstallString)` or `Process.Start(QuietUninstallString)` if available.
6. On success, reloads the list (D-13).
7. "Copy Command" copies the raw `UninstallString` to clipboard.
8. On failure, shows error InfoBar.

## Shared UI Patterns

### Page Header

All four pages use the same header pattern (from Phase 5):

```xml
<Grid Grid.Row="0">
    <Grid.ColumnDefinitions>
        <ColumnDefinition Width="*" />
        <ColumnDefinition Width="Auto" />
    </Grid.ColumnDefinitions>
    <StackPanel Grid.Column="0">
        <TextBlock Text="{Title}" Style="{StaticResource TitleTextBlockStyle}" />
        <TextBlock Text="{Subtitle}"
                   Margin="0,4,0,0"
                   Foreground="{ThemeResource TextFillColorSecondaryBrush}" />
    </StackPanel>
    <StackPanel Grid.Column="1" Orientation="Horizontal" Spacing="8" VerticalAlignment="Top">
        <Button Content="Refresh" Click="OnRefreshClick" />
    </StackPanel>
</Grid>
```

### Elevation InfoBar

Pages that modify machine-wide settings show an `InfoBar` when not elevated:

```xml
<InfoBar x:Name="ElevationBar"
         Grid.Row="1"
         Margin="0,16,0,0"
         IsOpen="False"
         IsClosable="False"
         Severity="Warning"
         Title="Administrator rights required"
         Message="Some operations on this page require elevation. Run Vain Tools as administrator to perform them." />
```

### Card Container

All custom sections use the same card container (from Phase 5):

```xml
<Border Margin="0,16,0,0"
        Padding="16"
        CornerRadius="8"
        VerticalAlignment="Top"
        Background="{ThemeResource CardBackgroundFillColorDefaultBrush}"
        BorderBrush="{ThemeResource DividerStrokeColorDefaultBrush}"
        BorderThickness="1">
    <!-- Section content -->
</Border>
```

### Loading State

While async data loads, pages show a `ProgressRing`:

```xml
<ProgressRing x:Name="LoadingRing"
              Grid.Row="2"
              Width="32" Height="32"
              IsActive="True"
              Visibility="{x:Bind IsLoading, Mode=OneWay}" />
```

### Empty State

When a list has no items, pages show a placeholder `TextBlock`:

```xml
<TextBlock Text="{EmptyStateMessage}"
           Foreground="{ThemeResource TextFillColorTertiaryBrush}"
           Visibility="{x:Bind HasItems, Mode=OneWay, Converter={StaticResource InverseBoolToVisibilityConverter}}" />
```

### Error State

When a service call fails, pages show an `InfoBar` with error details:

```xml
<InfoBar x:Name="ErrorBar"
         Grid.Row="1"
         Margin="0,16,0,0"
         IsOpen="False"
         IsClosable="True"
         Severity="Error"
         Title="Error"
         Message="{x:Bind ErrorMessage, Mode=OneWay}" />
```

### Destructive Confirmation Dialog

All destructive operations use a `ContentDialog` with explicit confirmation:

```xml
<ContentDialog x:Name="ConfirmDialog"
               Title="{ConfirmTitle}"
               Content="{ConfirmMessage}"
               PrimaryButtonText="Confirm"
               CloseButtonText="Don't Remove"
               DefaultButton="Close" />
```
