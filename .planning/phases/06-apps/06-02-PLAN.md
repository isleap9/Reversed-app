**Service layer (D-08, D-09):**

Create `IStoreService.cs`:
```csharp
namespace VainTools.App.Services;

public interface IStoreService
{
    IReadOnlyList<StoreApp> SearchApps(string query);
    Task<ProcessResult> InstallAppAsync(string appId);
}
```

Create `StoreApp.cs` model:
```csharp
namespace VainTools.App.Services;

public sealed record StoreApp(
    string Name,
    string Id,
    string Version,
    string Source);
```

Create `StoreService.cs` using `IProcessRunner` for winget CLI:
- Constructor injects `IProcessRunner`, `ILogger<StoreService>`
- `SearchApps(query)`:
  - Runs `winget search "<query>" --accept-source-agreements` via `_processRunner.RunAsync("winget", ...)`
  - If exit code != 0, logs warning and returns empty list
  - Parses tabular output: skip header lines, split on whitespace, extract Name, Id, Version, Source
  - **Defensive parsing:** handle missing fields, varying column widths, empty results
  - If `--format json` is supported (winget 1.4+), prefer JSON parsing with fallback to tabular
- `InstallAppAsync(appId)`:
  - Runs `winget install --id <appId> --exact --accept-source-agreements --accept-package-agreements` via `_processRunner.RunAsync("winget", ...)`
  - Returns `ProcessResult` with exit code, stdout, stderr
- Uses `ILogger<StoreService>` for logging
- Does NOT catch exceptions — lets them propagate to ViewModel

**ViewModel:**

Create `StoreViewModel.cs` extending `ViewModelBase`:
- `[ObservableProperty] public partial string StatusMessage { get; set; } = "Ready";`
- `[ObservableProperty] public partial bool IsElevated { get; set; }`
- `[ObservableProperty] public partial bool IsLoading { get; set; }`
- `[ObservableProperty] public partial string ErrorMessage { get; set; } = string.Empty;`
- `[ObservableProperty] public partial string SearchQuery { get; set; } = string.Empty;`
- `public ObservableCollection<StoreApp> Apps { get; } = [];`
- Constructor injects `IStoreService`, `IRegistryTweakService`, `IDialogService`, `IInfoBarService`, `ILogger<StoreViewModel>`
- Sets `IsElevated = registry.IsElevated` in constructor
- `[RelayCommand] public async Task SearchAsync()`:
  - Validates `SearchQuery` is not empty
  - Sets `IsLoading = true`
  - Calls `_storeService.SearchApps(SearchQuery)`
  - Populates `Apps` collection
  - Sets `IsLoading = false`
  - Shows error InfoBar on failure (D-12)
- `[RelayCommand(CanExecute = nameof(CanInstallApp))] public async Task InstallAppAsync(StoreApp? app)`:
  - Check elevation (D-10) — show error if not elevated
  - Confirm via `IDialogService.ConfirmAsync` showing app name + ID (D-11)
  - Sets `IsLoading = true`, `StatusMessage = $"Installing {app.Name}…"`
  - Calls `_storeService.InstallAppAsync(app.Id)`
  - On success (exit code 0): shows success InfoBar
  - On failure: shows error InfoBar with stderr (D-12)
  - Sets `IsLoading = false`
- `[RelayCommand] public async Task RefreshAsync()` — re-runs search with current query
- `private bool CanInstallApp(StoreApp? app) => app is not null && IsElevated && !IsLoading;`
