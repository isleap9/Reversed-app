Create `OptionalFeaturesService.cs` using DISM API via P/Invoke:
- Use `LibraryImport("DismApi.dll")` for DISM functions
- `GetFeatures()` — calls `DismApi.Initialize()`, `DismApi.GetFeatures()`, maps to `OptionalFeature` records, calls `DismApi.Shutdown()` in finally
- `EnableFeatureAsync(featureName)` — calls `DismApi.Initialize()`, `DismApi.EnableFeature()` with `DismOnline` session, `DismApi.Shutdown()` in finally
- `DisableFeatureAsync(featureName)` — calls `DismApi.Initialize()`, `DismApi.DisableFeature()` with `DismOnline` session, `DismApi.Shutdown()` in finally
- All DISM calls wrapped in `Task.Run()` to avoid blocking UI thread
- Uses `ILogger<OptionalFeaturesService>` for logging
- Does NOT catch exceptions — lets them propagate
- **Note:** If `DismApi.dll` P/Invoke proves too complex, fallback to `Process.Start("dism.exe", "/Online /Enable-Feature /FeatureName:<name>")` — document the choice in code comments

<threat_model>
| ID | Threat | STRIDE | Mitigation |
|----|--------|--------|------------|
| T-06-01 | Appx package removal modifies system state | Tampering | Elevation check (D-10) + confirmation dialog (D-11) before RemovePackageAsync |
| T-06-02 | UninstallString from registry could contain malicious command | Tampering | Display raw string to user before execution; use QuietUninstallString when available (D-04) |
| T-06-03 | Process.Start on UninstallString could execute arbitrary code | Elevation of Privilege | Only execute after elevation check + user confirmation; show the command in the confirmation dialog |
| T-06-04 | DISM feature enable/disable modifies system configuration | Tampering | Elevation check (D-10) + confirmation for Disable (D-11) |
| T-06-05 | Registry values could contain injection payloads | Tampering | Sanitize display values; never execute registry values directly |
| T-06-06 | winget install could install untrusted packages | Tampering | Confirmation dialog showing app name + ID before install (D-11) |
| T-06-07 | Error messages could leak system information | Information Disclosure | Show user-friendly error messages; log full details via ILogger (D-12) |
| T-06-08 | Clipboard data could be accessed by other processes | Information Disclosure | Only copy explicit user-requested data; no sensitive data in clipboard |
</threat_model>
