# Plan 04-02: Performance Tweaks & Performance Page

## Goal

Implement the Performance page with 8 registry-based performance toggles using the existing
`RegistryTweakService` + `TweakCatalog` + `TweakList` pattern. Follows the exact same
architecture as the Security page (Plan 04-01).

**Decisions:** D-03 (RegistryTweakService for Performance), D-05 (reuse Phase 3 elevation pattern), D-06 (TweakList for Performance page)

## Requirements

| ID | Description |
|----|-------------|
| PERF-01 | Performance page displays 8 toggles: Skip Tick, Platform Tick, Timer Expiration, MPO, GPU Scheduling, Working Set, Game Mode, Game DVR |
| PERF-02 | GPU Scheduling uses `HwSchMode` with enabled value `2` (not `1`) — toggle must handle this correctly |
| PERF-03 | MPO (`OverlayTestMode`) requires Explorer restart — `RequiresExplorerRestart = true` |
| PERF-04 | Game Mode and Game DVR write to HKCU — no admin required |

## must_haves

- D-03: Performance toggles use RegistryTweakService (no new service)
- D-05: Reuse Phase 3 elevation pattern (IsElevated, applied vs reboot-required, RestartExplorerAsync)
- D-06: Performance page uses TweakList control

## Research Notes

### Registry Paths (from 04-RESEARCH.md §2.1)

| ID | Hive | Key Path | Value Name | Enabled | Disabled | Default | Admin | Explorer Restart |
|----|------|----------|------------|---------|----------|---------|-------|------------------|
| `perf-skiptick` | HKLM | `SYSTEM\CurrentControlSet\Control\Session Manager\kernel` | `SkipTickOverride` | 1 | 0 | 0 | Yes | No |
| `perf-platform-tick` | HKLM | `SYSTEM\CurrentControlSet\Control\Session Manager\kernel` | `UsePlatformTick` | 1 | 0 | 0 | Yes | No |
| `perf-timer-expiration` | HKLM | `SYSTEM\CurrentControlSet\Control\Session Manager\kernel` | `TimerExpiration` | 1 | 0 | 0 | Yes | No |
| `perf-mpo` | HKLM | `SOFTWARE\Microsoft\Windows\Dwm` | `OverlayTestMode` | 1 | 0 | 0 | Yes | **Yes** |
| `perf-gpu-scheduling` | HKLM | `SYSTEM\CurrentControlSet\Control\GraphicsDrivers` | `HwSchMode` | **2** | **1** | 2 | Yes | No |
| `perf-working-set` | HKLM | `SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management` | `LargeSystemCache` | 1 | 0 | 0 | Yes | No |
| `perf-game-mode` | **HKCU** | `Software\Microsoft\GameBar` | `AllowAutoGameMode` | 1 | 0 | 1 | **No** | No |
| `perf-game-dvr` | **HKCU** | `System\GameConfigStore` | `GameDVR_Enabled` | 1 | 0 | 1 | **No** | No |

### Key Observations

- **6 tweaks write to HKLM** → require admin elevation
- **2 tweaks write to HKCU** → no admin required (Game Mode, Game DVR)
- **1 tweak requires Explorer restart** — MPO (`perf-mpo`) because it changes DWM composition
- **GPU Scheduling is inverted**: `HwSchMode` value `2` = enabled (on), `1` = disabled (off). This is unusual — the "enabled" state is `2`, not `1`. `EnabledValue = 2`, `DisabledValue = 1`.
- **Timer resolution tweaks** (`SkipTickOverride`, `UsePlatformTick`, `TimerExpiration`) all live under the same `kernel` key — they are related timer resolution settings
- **Working Set** (`LargeSystemCache`): `1` = large system cache (favors system performance over app responsiveness), `0` = default

### Existing Pattern

Same as Security — add a `Performance` collection to `TweakCatalog` and wire up the page.

## Design

### Architecture

Identical to Plan 04-01 (Security):

1. **TweakCatalog** — add `Performance` collection
2. **RegistryTweakService** — no changes needed
3. **TweakPageViewModel** — no changes needed
4. **TweakList** control — no changes needed
5. **PerformancePage** — wire factory to control

### Tweak Definitions

| Property | Value |
|----------|-------|
| `Hive` | `LocalMachine` (6 tweaks), `CurrentUser` (2 tweaks) |
| `RequiresAdmin` | `true` (6 HKLM tweaks), `false` (2 HKCU tweaks) |
| `RequiresExplorerRestart` | `true` (MPO only), `false` (all others) |
| `ValueKind` | `DWord` (default, all 8) |

### Special Handling

- **GPU Scheduling** (`perf-gpu-scheduling`): `EnabledValue = 2`, `DisabledValue = 1`. The toggle name is "Hardware-Accelerated GPU Scheduling" — when the user enables this toggle, it writes `2` (enabling GPU scheduling). When the user disables this toggle, it writes `1` (disabling GPU scheduling).
- **MPO** (`perf-mpo`): `RequiresExplorerRestart = true`. The `TweakList` control already handles this via `HasExplorerTweaks` and `RestartExplorerButton`.
- **Game Mode** (`perf-game-mode`): `Hive = CurrentUser`, `RequiresAdmin = false`. This tweak works without elevation.
- **Game DVR** (`perf-game-dvr`): `Hive = CurrentUser`, `RequiresAdmin = false`. This tweak works without elevation.
