## Verification

**Must-Haves (truths):**
- WinUI 3 application runs with MVVM architecture
- DI container resolves services correctly
- View models inherit from ObservableObject
- Service interfaces are properly abstracted

**Prohibitions:**
- No direct hardware API calls in ViewModels (must go through services)
- No hardcoded paths in any component
- No static singletons (use DI instead)

**Success Criteria:**
1. Project compiles without warnings
2. App runs and displays MainWindow
3. DI container resolves all registered services
4. Base MVVM classes are functional and testable
5. Navigation service can navigate between pages
