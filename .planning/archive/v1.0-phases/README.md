# Planning Artifacts

This directory contains phased implementation plans for the VainTools project.

## Phase Numbering Convention
- Integer phases (1, 2, 3): Major milestones
- Decimal phases (2.1, 2.2): Inserts within phases

## Phase Directory Structure
Each phase directory contains:
- `{N}-{N}-PLAN.md` - Detailed implementation plans
- `{N}-{N}-VALIDATION.md` - Verification strategy
- `{N}-{N}-CONTEXT.md` - Phase-specific context (if needed)
- `{N}-{N}-RESEARCH.md` - Research findings (if needed)
